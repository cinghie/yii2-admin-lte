# Carousel

`cinghie\adminlte\widgets\Carousel` renders the Bootstrap 3 carousel used by AdminLTE 2, while encoding slide content, captions and custom controls by default.

## Basic usage

```php
use cinghie\adminlte\widgets\Carousel;

echo Carousel::widget([
    'items' => [
        [
            'content' => 'First slide',
            'caption' => 'First caption',
        ],
        [
            'content' => 'Second slide',
            'caption' => 'Second caption',
        ],
    ],
]);
```

The first slide is activated automatically. Indicators and previous/next controls are enabled by default, matching the Bootstrap/AdminLTE example.

## Images and trusted HTML

Slide content is encoded by default. When the content is HTML generated by your application, opt in explicitly per slide:

```php
use cinghie\adminlte\widgets\Carousel;
use yii\helpers\Html;

echo Carousel::widget([
    'items' => [
        [
            'content' => Html::img('/images/slide-1.jpg', [
                'alt' => 'First slide',
                'class' => 'img-responsive',
            ]),
            'caption' => '<strong>First slide</strong>',
            'encodeContent' => false,
            'encodeCaption' => false,
        ],
    ],
]);
```

Only disable encoding for HTML that is generated or sanitized by the application. Do not disable it for untrusted user input.

## Options

The widget inherits the Bootstrap 3 Carousel options and adds these safety options:

- `encodeContent` — encode slide content by default; defaults to `true`.
- `encodeCaptions` — encode captions by default; defaults to `true`.
- `encodeControls` — encode custom previous/next labels; defaults to `true`.

Each array item may override `encodeContent` and `encodeCaption`.

Standard options such as `showIndicators`, `controls`, `clientOptions`, `options`, and item-level `options` remain available.

Example without indicators or controls:

```php
echo Carousel::widget([
    'showIndicators' => false,
    'controls' => false,
    'clientOptions' => [
        'interval' => 5000,
        'pause' => 'hover',
    ],
    'items' => [
        'First slide',
        'Second slide',
    ],
]);
```

The Bootstrap plugin asset is registered by `yii2-bootstrap`; no additional AdminLTE asset bundle is required.
